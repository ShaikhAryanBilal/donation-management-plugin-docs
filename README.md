## Strategic Highlights for Portfolio
If you are reviewing this project for a senior development role, please note the following high-impact engineering solutions:

1.  **Stateful Cart System**: Implementation of a proprietary, session-based basket system that allows donors to manage multiple causes in a single transaction asynchronously.
2.  **Proprietary Financial Engine**: A custom-built system handling complex business rules, multi-currency validation, and automated tax-receipt generation.
3.  **Automated Fulfillment Workflows**: Integration of Geocoding and dynamic PDF generation to eliminate manual administrative overhead and ensure 100% data accuracy.
4.  **Security-First Architecture**: Tokenized payment handling and custom-built REST endpoints with strict permission callbacks.
